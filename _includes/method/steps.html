Step 1 · Reachability scoring

Scoring workspace goal regions

Each candidate WGR is scored by fϕ from the scene embedding zenv. A temperature softmax, mixed with a uniform prior, turns the scores into sampling probabilities p̃i, which decide how many goal configurations each region receives.

Step 2 · Path samples

Diffusion denoising

For each goal configuration qg, a batch of Gaussian-noise sequences is denoised with DDIM into path samples conditioned on qs, qg and zenv. The model is multimodal, so samples for the same goal can follow different routes. Colors mark the goal region each sample leads to. The pooled configurations guide the tree in the next step.

Step 3 · Tree expansion

Growing the tree toward weighted goals

On a goal-biased iteration the planner takes the highest-weighted goal qg, extends toward a diffusion sample (X), then tries to extend toward qg itself (Y). Success rewards that goal's weight and failure penalizes it, so exploration shifts to goals that prove reachable.
