Pseudocode — Reachability-aware WGR scoring
Require: observation 𝓔 = (xrgb, xdepth), regions {WGRi}i=1N
  1. zenv ← Encoder(xrgb, xdepth)
  2. for i = 1 … N do
  3. si ← σ(headcls([zenv ‖ WGRi]))
  4. end for
  5. pi ← softmax(si / τ)
  6. p̃i ← (1 − α) pi + α / N
  7. GR ← GoalRegionSampler({WGRi}, {p̃i})

Algorithm 1 — Learning-informed sampling-based planner with reachability-aware WGR selection
Require: start qs, regions {WGRi} with scores {si}, goal bias β
  1. V ← {qs}; E ← ∅
  2. {pi} ← ComputeWeights({si})
  3. GR ← GoalRegionSampler({WGRi}, {pi})
  4. while not StopCondition() do
  5. if BiasToGoal() then
  6. qg ← SampleWeightedGoal(GR)
  7. qX→ ← πθ(qt | qs, qg, 𝓔)
  8. goal_biased ← true
  9. else
  10. qX→ ← GenRandomConf()
  11. goal_biased ← false
  12. end if
  13. qnear ← Nearest(𝒯, qX→)
  14. (qXnew, sX) ← Extend(qnear, qX→)
  15. if sX then
  16. AddNode, AddEdge(qnear, qXnew)
  17. end if
  18. if goal_biased then
  19. (qYnew, sY) ← Extend(qnear, qg)
  20. if sY then
  21. AddNode, AddEdge(qnear, qYnew)
  22. Reward(GR, qg)
  23. else
  24. Penalize(GR, qg)
  25. end if
  26. end if
  27. end while
  28. return 𝓅 ← ExtractPath(𝒯)
